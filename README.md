# かくれんぼ — Game Library

ゲーム・カード・参加者の記録を閲覧するReact / TypeScript製のPWAです。画面・検索・管理画面のコードを公開しています。

## 起動する

Node.js 22.12以上で実行してください。

```sh
npm ci --ignore-scripts
npm run dev:demo
```

デモは架空のデータを使い、Supabase・本番DB・通知送信へ接続しません。Vercelのプレビューはデモ版で、本番環境では運営者が非公開で設定した接続先を使います。

## 編集する

- `src/`: 画面とデータ処理
- `src/admin/`: 管理画面
- `public/`: 静的アセット
- `tests/`: 動作確認

```sh
npm run typecheck
npm test
npm run build
npm run build:demo
```

変更はForkとPull Requestから提案できます。[参加方法](CONTRIBUTING.md)を参照してください。本番DBへの反映権限は付与されません。

## 既知の開発ツールの問題

Viteが使用するpicomatchにReDoSの既知の問題があります。細工されたglobパターンによりNode.jsの処理が長時間停止する可能性があります。開発用依存の監査では関連パッケージを含めHigh 5件と表示されます。解消済みとは扱っていません。

開発サーバーは127.0.0.1に限定し、公開ネットワークへ公開しないでください。信頼できないコード・設定・globパターンを開発環境へ取り込まないでください。完成したブラウザ用ビルドにこれらのパッケージを含めない構成ですが、あらゆる利用形態の安全性を保証するものではありません。

CIでは動作確認とセキュリティ監査を独立して実行します。既知の問題が残る間、セキュリティ検査は失敗します。[詳細](SECURITY.md)。

## 自分のDBへ接続する

独立したSupabase環境と`.env.example`を使ってください。秘密鍵・service-roleキーはクライアントへ設定しないでください。SQLは既存のテーブル構成への追加・検証用で、空のDBを作る完全な初期スキーマは含みません。Forkして通常版をデプロイする場合は、VercelのProductionだけに公開用の接続設定を登録し、CSPの接続先を自分の環境に合わせてください。管理用の秘密鍵は不要です。

## 共同開発と本番反映

公開リポジトリを開発の中心にします。ForkとPull Requestで変更を提案し、プレビューとテストで確認後、管理者がmainへ採用します。Vercelとの接続設定が完了すると、mainへの変更は既存のアプリへ自動反映されます。

プレビュー・外部からの変更提案では架空データを使い、本番のSupabase接続設定を渡しません。DB管理権限・管理用アカウント・秘密鍵はコードの公開対象外です。ブラウザが使う公開キーとURLは閲覧者から確認できるため、データの保護はSupabaseのRLSと権限設定で行います。掲載データの編集は、別途許可された管理者だけが行います。
